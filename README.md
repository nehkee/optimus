# potatohead

A static website of Spud, the singing potato.

Open `index.html` in a browser (no build step) and press **Make Spud sing**. The song is synthesized live with the Web Audio API, and Spud's mouth, lyrics and floating notes follow along.

Files:
- `index.html`: the page and the SVG potato
- `style.css`: styles and animations
- `script.js`: the song, the synthesized voice and the lip sync
